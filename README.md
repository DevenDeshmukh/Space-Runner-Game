# Space Runner Game 🚀

Space Runner is a fun and fast-paced 2D platformer game where you control an astronaut avoiding asteroids and alien monsters. The game challenges your reflexes as you jump to avoid increasingly difficult obstacles while aiming for a high score!

## 📋 Features
- **Endless Gameplay:** The game continues until you collide with an obstacle. The longer you last, the faster the obstacles get!
- **Dynamic Obstacles:** Asteroids and alien monsters come from the top and bottom of the screen.
- **Jump Mechanic:** Press **Space** to jump over obstacles.
- **Score Tracking:** Your score increases over time based on how long you survive.

## 🛠️ Technologies Used
- **React.js:** For building the user interface and managing the game logic.
- **HTML5 Canvas:** For rendering the game scene and animations.
- **JavaScript:** For controlling the game mechanics, such as collision detection and obstacle movement.

## 🚀 Getting Started

### 1. Clone the repository
To get started with this project, first clone the repository to your local machine:

```bash
git clone https://github.com/your-username/space-runner-game.git
```
2. Install Dependencies
Navigate to the project directory and install the required dependencies:
```
cd space-runner-game
npm install
```
3. Start the Game
Once the dependencies are installed, you can start the game by running:
```
npm start
```
This will launch the game in your default web browser.

##🎮 How to Play
Press Space to make your astronaut jump.

Avoid the asteroids and alien monsters coming at you.

The longer you survive, the faster the obstacles get!

Your score is displayed at the top of the screen and increases with time.
